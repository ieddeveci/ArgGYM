## Summary

`export-all` can export only eight of the twelve benchmark modes exposed by the inspector. The missing modes are `attack`, `defence`, `attack_defense`, and `perturbation`.

This was reproduced from owner `main` at `1fdc9db`.

## Evidence

The inspector lists twelve modes in [`ArgGYM_v2/inspector.py`](https://github.com/ieddeveci/ArgGYM/blob/1fdc9db03ddcc415abd82bef0f230ab31b8a6892/ArgGYM_v2/inspector.py#L33-L58). The export registry contains eight in [`ArgGYM_v2/core/export.py`](https://github.com/ieddeveci/ArgGYM/blob/1fdc9db03ddcc415abd82bef0f230ab31b8a6892/ArgGYM_v2/core/export.py#L16-L25).

Direct export attempts fail:

```text
$ python run.py export attack_defense /tmp/attack_defense.jsonl
unknown task attack_defense; known: [...]

$ python run.py export perturbation /tmp/perturbation.jsonl
unknown task perturbation; known: [...]
```

This also conflicts with the README's `export-all` description, which says it will “generate every task as JSONL” ([`README.md`](https://github.com/ieddeveci/ArgGYM/blob/1fdc9db03ddcc415abd82bef0f230ab31b8a6892/ArgGYM_v2/README.md#L8-L11)). The README says “Ten tasks, eleven modes,” while the inspector exposes twelve, and its task table omits `semantics_query` ([`README.md`](https://github.com/ieddeveci/ArgGYM/blob/1fdc9db03ddcc415abd82bef0f230ab31b8a6892/ArgGYM_v2/README.md#L57-L71)).

## Impact

The public export path omits one third of the modes that v2 presents as benchmark modes. An exported taskset therefore does not represent the complete benchmark inventory.

## Suggested fix

Use one authoritative mode registry for the CLI, inspector, exporter, and README. Add export entries for the three attack/defence modes and `perturbation`, or explicitly remove modes that are not intended to be benchmark tasks.
