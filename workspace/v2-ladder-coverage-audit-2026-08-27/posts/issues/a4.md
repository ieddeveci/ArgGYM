## Summary

`counter_argument_strict` has an inverted first difficulty step: generated L3
items require more answer directives on average than L6 items.

This was reproduced from owner `main` at `1fdc9db`.

## Evidence

[`build`](https://github.com/ieddeveci/ArgGYM/blob/1fdc9db03ddcc415abd82bef0f230ab31b8a6892/ArgGYM_v2/tasks/counter_argument.py#L77-L86)
allows depth 2 at L3, but enables the middle-target option only from L6.
[`counter_argument.py:155-171`](https://github.com/ieddeveci/ArgGYM/blob/1fdc9db03ddcc415abd82bef0f230ab31b8a6892/ArgGYM_v2/tasks/counter_argument.py#L155-L171)
also requires depth at least 3 before that cheaper target can be selected.

Across seeds 0-7 under last-link, the exact minimum answer sizes are:

```text
L3 mean: 3.0 directives
L6 mean: 2.5 directives
```

The frozen pilot taskset shows the same inversion over its full cells: 3.5 at
L3 and 3.0 at L6.

Reproduction:

```bash
cd ArgGYM_v2
python - <<'PY'
from statistics import mean
from tasks import counter_argument

for level in (3, 6):
    items = [
        counter_argument.make_item(
            level, seed, "last_link_elitist", allow_strict=True
        )
        for seed in range(8)
    ]
    print(level, mean(item.min_directives for item in items))
PY
```

## Impact

The first step of the nominal difficulty ladder points downward. Reported
L3-to-L6 model changes therefore mix model behavior with a generator-induced
reduction in the minimum solution size.

## Suggested fix

Give L3 chains enough depth to expose the same class of middle target, or
otherwise equalize the available target types without changing later levels.
Add a regression test over the official seed set that prevents the L3 minimum
from exceeding L6 for each ordering.
