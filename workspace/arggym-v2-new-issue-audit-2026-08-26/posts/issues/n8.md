## Summary

The notation and engine assign different meanings to `overruled`. A justified undercut can make the engine report `OVERRULED` even when neither the claim nor its contrary belongs to the extension, which the written definition calls `undecided`.

This was reproduced from owner `main` at `1fdc9db`.

## Evidence

[`NOTATION.md`](https://github.com/ieddeveci/ArgGYM/blob/1fdc9db03ddcc415abd82bef0f230ab31b8a6892/ArgGYM_v2/NOTATION.md#L102-L106) defines:

- `overruled`: the contrary is in the extension;
- `undecided`: neither the claim nor its contrary is in the extension.

The engine instead reports a conclusion as overruled whenever all arguments for it are OUT ([`aspic/engine.py`](https://github.com/ieddeveci/ArgGYM/blob/1fdc9db03ddcc415abd82bef0f230ab31b8a6892/ArgGYM_v2/aspic/engine.py#L273-L287)).

A minimal probe uses two premises, a defeasible rule for `qq0`, and a defeasible rule concluding the negated rule name, which undercuts the first rule:

```text
[premise: aa0]
[premise: bb0]
[defeasible r1: aa0 => qq0]
[defeasible r2: bb0 => -r1]
```

The engine labels `qq0` as `OVERRULED`. The grounded extension and the only preferred extension contain neither `qq0` nor `-qq0`. Under the documented definition, the same claim is `undecided`.

## Impact

Task prompts list the status labels without defining them, so `NOTATION.md` is the available contract for benchmark users. A solver that follows it can disagree with the scorer on undercut and undermine cases.

## Suggested fix

Choose one status contract and apply it consistently. If `overruled` means that every argument for a claim is defeated, document that definition and explain that an undercut or undermine need not establish the claim's contrary. Also define how extension sets map to labels under grounded, preferred, stable, and eager semantics.
